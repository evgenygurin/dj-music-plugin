# Правила разработки

## Инструменты
- **UV** – единственный способ установки зависимостей и запуска. Примеры:
  - `uv sync` – установить зависимости.
  - `uv run pytest -n auto` – запустить тесты параллельно.
  - `uv run ruff check` – линтинг.
  - `uv run alembic upgrade head` – миграции БД.

## Быстрые проверки
- `make check` – lint + type‑check + тесты + import‑linter.
- Хук `pre‑push` автоматически вызывает `make check`.
- При необходимости отключить проверки: `DJ_SKIP_CHECK=1 git push`.

## Структура кода
- Следуйте существующим паттернам в `app/`.
- Не создавайте файлы в корне, если они относятся к конкретному bounded‑context; помещайте их в соответствующий пакет.

## Тесты
- Пишите тесты для любой новой функции/изменения.
- Держите покрытие ≥ 80 % (проверяется `uv run pytest --cov`).
