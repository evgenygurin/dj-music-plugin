# Общие правила проекта

**Язык общения** – всегда отвечайте по‑русски, если не указано иное.

**Работа с зависимостями**
- Используйте только `uv` (`uv sync`, `uv run …`).
- Запрещено выполнять `python`, `pip`, `pytest`, `ruff`, `mypy` напрямую.

**CI / проверки**
- Основная команда: `make check` (линт, тип‑чек, тесты, import‑linter).
- Хук `pre‑push` автоматически запускает `make check`; пропустить можно `DJ_SKIP_CHECK=1 git push`.

**Коммиты**
- Краткие сообщения‑заголовки, без лишних деталей.
- Не меняйте чужие файлы без явного согласия.
